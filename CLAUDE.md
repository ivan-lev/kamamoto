# Kamamoto — рабочий контекст для Claude

Сайт частной коллекции японской керамики — https://kamamoto.ru. Разработчик один (Ivan Lev), общаемся на русском.

Репозиторий — монорепо **без npm workspaces**: в каждой папке свой `package.json`, `package-lock.json` и `node_modules`. Команды запускать внутри нужной папки.

## Карта репозитория

| Путь | Что это | Стек |
|---|---|---|
| `front/` | SPA посетителя + админка по `/admin` | React 19 + React Compiler, Vite 8, Redux Toolkit, react-router 8, SCSS (БЭМ) |
| `back/` | REST API под `/api` + раздача `/static` | Express 5, Mongoose 9, celebrate/Joi, JWT, multer |
| `mongo/` | скрипты синхронизации БД local ↔ VPS | bash, mongodump/mongorestore |
| `static/` | картинки и файлы контента. **Не в git** (есть в `.gitignore`), деплоится отдельно | раздаёт back |
| `docs/` | документация для людей (Astro Starlight) + changelog версий | Astro |
| `yuding/` | **побочный проект — не анализировать и не трогать без явной просьбы** | |
| `Caddyfile`, `docker-compose.yml`, `ops.sh` | прод-инфраструктура на VPS | Caddy, Docker |

## Команды

```bash
npm run dev            # из корня: front (vite :5173) + back (nodemon :3000) одновременно
```

Проверка перед тем, как считать задачу сделанной (тестов в проекте нет, CI только собирает проект — линтер никто, кроме нас, не запускает):

```bash
cd back  && npx tsc --noEmit && npx eslint .
cd front && npx tsc --noEmit && npx eslint . --max-warnings 0
cd front && npx stylelint '**/*.scss'      # если трогали стили
```

На 2026-09-27 все эти проверки проходят чисто — новых ошибок и предупреждений быть не должно.

## Жёсткие правила

- **Не запускать без явной просьбы**: `npm run db:push` (перезаписывает прод-БД), `db:pull` (перезаписывает локальную БД), любые `upload:*` (rsync на прод), `ops.sh`. Всё это — действия на проде.
- Не читать и не выводить значения из `.env`; не коммитить секреты.
- `yuding/` не трогать, даже если там есть незакоммиченные изменения — не включать их в свои коммиты.
- Коммитить только по просьбе. Формат: conventional commits на английском — `feat(scope): ...`, `fix(scope): ...`, `refactor(...)`, `chore(deps): ...`.

## Стиль кода (общий для front и back)

- ESLint `@antfu/eslint-config`: **табы**, одинарные кавычки, точки с запятой. На фронте JSX с пробелами внутри фигурных скобок: `{ value }`.
- Функции объявляются через `function`, а не стрелками (для компонентов, хендлеров, контроллеров). Новый код — `async/await`, а не `.then()`.
- Комментарии в коде — на русском, короткие, объясняют «почему».
- Константы — в `Object.freeze({...})` в папке `variables/`.

## Сквозные контракты front ↔ back (главный источник ошибок)

1. **Пути к файлам.** В БД хранится только имя файла (`thumb.webp`). Полный URL собирает бэкенд: `${STATIC_URL}/<раздел>/<ключ>/<файл>`. Для форм админки фронт шлёт заголовок `is-admin: 'true'` и получает сырые имена. Не все контроллеры поддерживают этот заголовок одинаково — см. [api.md](.claude/specs/api.md#заголовок-is-admin).
2. **Авторизация.** Любой `GET` — публичный (кроме `GET /api/users/`). Всё остальное требует `Authorization: Bearer <jwt>`. Отдельных «админских GET» нет, поэтому то, что отдаёт GET, видит весь интернет.
3. **У разных сущностей разные ключи**: лот и выставка — числовой `id`; гончар и термин — строковый `id`; стиль, категория, комплектация — `name`; партнёр и маркер — Mongo `_id`. Таблица — в [data-model.md](.claude/specs/data-model.md).
4. **Связи лота** (категория, стиль, гончар) фронт отправляет строкой (`name` / `id`), бэк сам находит ObjectId. Если по строке ничего не нашлось, в поле тихо попадает `undefined` и срабатывает дефолт схемы. Ошибки нет.
5. **Типы продублированы руками**: `front/src/types/*` и `back/src/types/*` (плюс Mongoose-схема и Joi-валидатор). Если меняется поле, правим все четыре места и фронтовую форму.
6. **Валидатор celebrate не пропускает лишние поля.** Если фронт пришлёт поле, которого нет в Joi-схеме, будет 400. Поэтому новое поле всегда добавляем и в валидатор.
7. **HTML страниц отдаёт бэк** (`back/src/controllers/pages.ts`): он берёт собранный `front/index.html` и подставляет `<title>`, `description`, `og:*`, `twitter:image` и добавляет `<link rel="canonical">` — для превью в мессенджерах и поисковиков. Теги находятся регулярками, поэтому в `index.html` нельзя менять их формат (`<meta property="og:title" content="..." />`, атрибуты в этом порядке, в одну строку) — иначе подстановка молча перестанет работать. Заголовки продублированы: `<Seo>` на фронте ↔ `pages.ts` (страницы записей) и `back/src/variables/staticPages.ts` (статичные страницы) — меняя одно, правь другое. Описания страниц живут только на бэке, фронтовый `Seo` рендерит один `<title>`. Подробности — в [back/CLAUDE.md](back/CLAUDE.md#html-страниц-и-мета-теги).
