# Project: kamamoto.ru

## Architecture
- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express, TypeScript
- Database: MongoDB, Mongoose
- Frontend and backend are separate applications.
- Deployment: Docker Compose, Caddy.

## Development rules

- Analyze existing architecture before making changes.
- Follow existing code conventions.
- Do not introduce unnecessary dependencies.
- Do not modify unrelated files.
- Do not change API contracts without checking frontend usage.
- Validate TypeScript types.
- Run relevant build and tests after changes.
- Do not modify production infrastructure.
- Never access production databases.
- Never expose secrets or environment variables.

## Workflow

1. Inspect relevant files.
2. Explain the proposed implementation.
3. Identify affected frontend and backend modules.
4. Implement changes.
5. Run checks and build.
6. Summarize modified files and remaining issues.
